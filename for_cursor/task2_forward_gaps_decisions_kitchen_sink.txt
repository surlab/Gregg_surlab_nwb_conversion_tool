A. acquisition_software / sorting_software — NOT a processing-module ordering bug
===============================================================================

**User correction:** Sorting software is not “lost” because `behavior` was
created first. Both belong on the **ecephys probe Device** (`spikeTimes_probe`
→ `Device.name`, e.g. `Neuropixel1.0`).

**Forward policy (locked):**
- `spikeTimes_acquisition_software` → probe `Device.description`
  (key=value: `acquisition_software=SpikeGLX` or plain text if single field).
- `spikeTimes_sorting_software` → **same probe Device.description**
  (key=value: `sorting_software=Kilosort4`).
- SessionInfo-first dual-read; schema mirror optional; fail if both disagree.
- **Do not** require a dedicated `processing/ecephys` module for sorting
  software in v1.
- **Do not** read sorting software from `_first_processing_module()` on reverse;
  read from the probe Device linked to spikeTimes (Units.device when present,
  else Device named `spikeTimes_probe`).

**Task 1 follow-up (table):** Update rows for `spikeTimes_sorting_software` from
`NWBFile/processing` → `processing_module_description` to
`NWBFile/devices` → `Device.description` (same target as acquisition_software,
distinct key in key=value text). Until Task 1 updates table, Task 2 follows
this decision doc.

Roundtrip failure was **reader targeting wrong NWB object**, not missing forward
write (forward NWB already had
`Neuropixel1.0.description = acquisition_software=SpikeGLX; sorting_software=Kilosort4`).

2. One shared probe Device
===============================================================================

**Locked:** One `Device` per distinct probe name (`Neuropixel1.0`). spikeTimes,
spikeWaves, and LFP share it when sessionInfo probe fields match.

**Forward:**
- `Units.device` → probe Device for every unit (spikeTimes stage).
- spikeWaves reuses existing Device; does not create a parallel probe Device.
- LFP electrode group → same Device (already implemented).

**Reverse:** Resolve probe fields from **Units.device** or named probe Device,
never `_first_device()` when ecephys modalities present.
